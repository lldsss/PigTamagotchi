# Пуня 🐷

Telegram-бот на **aiogram 3** и Mini App с маленькой свинкой. Светлая розовая комната, анимированный питомец, минимум текста. Интерфейс на русском, адаптирован для телефона и компьютера.

## Размещение на BotHost

Основной вариант для текущего проекта — **GitHub → BotHost**. Настройки приватного репозитория, собственного Dockerfile, HTTPS-домена, порта и постоянной базы: [docs/bothost.md](docs/bothost.md).

## Запуск без домашнего VPN и туннеля

Для работы независимо от Mac разместите бота и Mini App на облачном сервере. Подготовлен `Dockerfile`; пошаговая инструкция для Railway с HTTPS и постоянным диском — в [docs/hosting.md](docs/hosting.md). Само размещение ещё не выполнено.

## Локальный запуск

Нужен Python 3.11 или новее. В деморежиме токен и Telegram не требуются.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
cp .env.example .env
python -m pig_tamagotchi
```

Откройте **http://127.0.0.1:8080**. В примере включён `DEMO_MODE=true`. Демо сохраняется в SQLite и привязано к cookie браузера. При удалении cookie появится новая свинка. В деморежиме бот не запускается.

## Быстрый запуск в Telegram с Mac

Установите `cloudflared` (`brew install cloudflared`), укажите токен в `BOT_TOKEN` файла `.env` и выполните:

```sh
bash scripts/start-local.sh
```

Скрипт установит отсутствующие зависимости, получит временный HTTPS-адрес, запустит бота и автоматически передаст ему адрес Mini App. Он не меняет `.env` и не выводит токен. Отправьте боту `/start`. Терминал и компьютер должны оставаться включёнными; `Ctrl+C` останавливает бота и туннель. При следующем запуске новый адрес устанавливается автоматически. Этот способ предназначен для локального тестирования.

Если появляется **Cloudflare 1033**, туннель не подключён либо открыта ссылка от предыдущего запуска. Остановите скрипт (`Ctrl+C`), запустите снова и дождитесь «Туннель подключён к Cloudflare». В Telegram отправьте новый `/start` и используйте новую кнопку. Скрипт использует HTTP/2 и ждёт подтверждения соединения до 90 секунд. Журнал сохраняется в `data/cloudflared.log`; последние строки: `tail -n 20 data/cloudflared.log`. Другой транспорт можно выбрать через `TUNNEL_PROTOCOL=auto bash scripts/start-local.sh`.

## Подключение к Telegram

1. Создайте бота через **@BotFather**, командой `/newbot`.
2. Разместите приложение на сервере с Python и постоянным диском. Настройте HTTPS через обратный прокси на порт `8080`. Он должен передавать пути `/`, `/api/*` и файлы интерфейса без изменений. Сертификат должен быть доверенным.
3. В `.env` задайте `BOT_TOKEN`, `WEBAPP_URL=https://ваш-домен` и **`DEMO_MODE=false`**. Не публикуйте `.env`. Для контейнера задайте `HOST=0.0.0.0`, для прокси на том же сервере оставьте `127.0.0.1`.
4. Запустите `python -m pig_tamagotchi` и держите процесс запущенным через менеджер процессов. Используется long polling: для одного бота запускайте один экземпляр. Если ранее использовали webhook, удалите его перед запуском polling.
5. Отправьте боту `/start` в личных сообщениях и нажмите **«К моей свинке»**. Кнопка меню **«Моя свинка»** устанавливается автоматически. `/play` повторно показывает кнопку.

Токен остаётся на сервере. Каждый запрос проверяет подпись Telegram `initData` и его возраст (до 24 часов); после истечения срока нужно переоткрыть приложение. Пользователь определяется по подписанному Telegram ID. Демо и реальные игроки используют разные пространства идентификаторов. Не включайте деморежим в рабочем боте.

## Как играть

| Действие | Эффект | Награда | Пауза |
|---|---|---|---|
| Кормление | +25 сытости | 10 XP, 8 монет | 1 минута |
| Прогулка | +22 счастья, −12 энергии, −8 сытости и чистоты | 16 XP, 12 монет | 5 минут |
| Игра | +18 счастья, −12 энергии | 12 XP, 10 монет | 2 минуты |
| Купание | +35 чистоты, +5 счастья | 10 XP, 8 монет | 3 минуты |
| Домик | Подушка → цветы → гирлянда | 25 XP | 6 часов |

Улучшения стоят 30, 60 и 100 монет; первое доступно сразу после накопления монет. Пять уровней открываются при 0, 50, 140, 300 и 550 XP. Каждый час энергия восстанавливается на 8, сытость падает на 4, счастье на 3, чистота на 2. Это учитывается и после закрытия приложения. Свинка не погибает. Поглаживание по нажатию на Пуню — анимация без награды и таймера.

Прогресс и таймеры хранятся в `data/pigs.sqlite3`; путь задаётся через `DATABASE_PATH`. При переносе сохраняйте базу, а при резервном копировании работающей базы используйте SQLite backup API. Для нескольких серверов потребуется общая БД вместо локальной SQLite.

## Структура и проверки

- `src/pig_tamagotchi/` — бот, HTTP API, проверка авторизации, правила и SQLite.
- `web/` — HTML/CSS/JavaScript и авторская SVG-свинка; сборка фронтенда не требуется.
- `tests/` — правила игры, конкурентные действия, авторизация и HTTP API.

```sh
python -m unittest discover -s tests -v
ruff check .
ruff format --check .
```

Шрифты необязательны и загружаются из Google Fonts; при отсутствии сети используется системный шрифт. Telegram SDK загружается с официального домена Telegram.

Интеграция следует [документации Telegram Mini Apps](https://core.telegram.org/bots/webapps) и [aiogram](https://docs.aiogram.dev/en/latest/).
