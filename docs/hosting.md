# Запуск на Railway без локального туннеля

Бот и Mini App работают в одном контейнере на сервере. Mac, домашний VPN и Cloudflare Tunnel для работы приложения не нужны. Проверять доступ к Telegram нужно с сервера; доступ к самому Mini App — также с телефона пользователя.

## Размещение

1. Создайте аккаунт на [Railway](https://railway.com/). Проверьте доступность регистрации и оплаты для своего аккаунта. Тариф Hobby начинается с $5 в месяц; итог зависит от ресурсов. Ознакомьтесь с [актуальными тарифами](https://docs.railway.com/pricing).
2. Загрузите проект в свой GitHub-репозиторий. **Не загружайте `.env`, `.venv` и `data/`** — они уже перечислены в `.gitignore`.
3. В Railway создайте проект и сервис из этого GitHub-репозитория. В корне есть `Dockerfile`, который собирает приложение вместе с интерфейсом.
4. Добавьте постоянный **Volume** с точкой монтирования `/data`, чтобы свинки сохранялись при пересоздании контейнера. Используйте один экземпляр сервиса.
5. В настройках сервиса откройте **Networking → Public Networking → Generate Domain**. Для нашего контейнера укажите целевой порт `8080`. Railway выдаёт публичный домен с HTTPS.
6. В **Variables** задайте:

   ```dotenv
   BOT_TOKEN=токен_из_BotFather
   WEBAPP_URL=https://выданный-домен.up.railway.app
   DEMO_MODE=false
   HOST=0.0.0.0
   PORT=8080
   DATABASE_PATH=/data/pigs.sqlite3
   ```

   Вместо примера `WEBAPP_URL` вставьте настоящий адрес. Токен вводите только в Variables. Файл `.env` на сервер загружать не нужно.
7. Выполните Deploy/Redeploy после настройки переменных и диска. Если первая сборка запустилась до добавления переменных, её ошибка ожидаема: приложение требует токен и HTTPS-адрес.
8. Остановите локальный экземпляр бота через `Ctrl+C`, чтобы два процесса не получали обновления одного бота. Отправьте боту `/start` и откройте новую кнопку.

## Проверка

- В логах сервиса не должно быть ошибок подключения к Telegram и конфликта polling.
- Публичный адрес должен показывать интерфейс. В обычном браузере вне Telegram сообщение об авторизации ожидаемо: для игры откройте Mini App через бота.
- Выполните действие, закройте Mini App и откройте снова: прогресс должен сохраниться.
- Проверку сохранения после Redeploy выполняйте только после подключения Volume.
- Если сервис поддерживает автоматическое засыпание, отключите его: бот использует постоянный long polling.

Репозиторий подготовлен к сборке контейнера, но размещение и проверка реального сервера требуют аккаунта хостинга. Если Railway недоступен или его нельзя оплатить, тот же Dockerfile можно использовать на VPS с доступом к Telegram; для него отдельно нужны домен и обратный прокси с HTTPS.

Документация: [Docker](https://docs.railway.com/builds/dockerfiles), [HTTPS](https://docs.railway.com/networking/public-networking), [постоянные диски](https://docs.railway.com/volumes).
